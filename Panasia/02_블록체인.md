# 📘 2단계: 블록체인, 모두의 공책은 어떻게 돌아갈까?

## 1. 이름 뜯어보기: 블록 + 체인
- **블록(Block)** = 공책의 **한 페이지**. 여러 거래 기록이 담겨 있어요.
  ```
  [블록 #100]
  - A → B : 1코인
  - C → D : 3코인
  - E → F : 0.5코인
  ```
- **체인(Chain)** = 페이지들이 **순서대로 단단히 묶여 있다**는 뜻

📚 **블록체인 = 페이지(블록)들이 사슬(체인)처럼 이어진 공책**

## 2. 페이지를 단단히 묶는 "지문" = 해시(Hash)
- 페이지 내용으로 만든 지문. **글자 하나만 바뀌어도 지문이 완전히 달라져요.**
- **각 페이지에는 바로 앞 페이지의 지문도 같이 적혀요.**

```
[블록 99]          [블록 100]          [블록 101]
내용...            앞 지문: 99의 지문   앞 지문: 100의 지문
지문: abc          내용...             내용...
                   지문: def           지문: ghi
```

🕵️ 누가 99번 페이지를 몰래 고치면?
→ 99번 지문이 바뀜 → 100번에 적힌 "앞 지문"과 안 맞음 → **바로 들통!**
그래서 블록체인은 **한번 적히면 고치기 거의 불가능**해요.

## 3. 공책을 가진 컴퓨터 = 노드(Node)
- 블록체인 공책 복사본을 가진 **컴퓨터 하나하나**
- 비트코인은 전 세계 수만 대가 같은 공책을 들고 있어요.
- 몇 대가 꺼지거나 해킹당해도 **나머지가 멀쩡하면 안전**해요.

## 4. 누가 다음 페이지를 쓸까? = 합의(Consensus)

### ⛏️ 작업증명 (PoW, Proof of Work)
- **어려운 수학 퍼즐을 제일 먼저 푼 사람**이 다음 페이지를 씀
- 컴퓨터와 **전기를 엄청 씀**
- 이긴 사람은 **새 코인을 상으로 받음** → **채굴(Mining)**, **채굴자(Miner)**
- 🏃 비유: 달리기 시합 1등이 쓸 권리를 가짐
- 예: **비트코인**

### 🔒 지분증명 (PoS, Proof of Stake)
- **코인을 많이 맡겨둔(담보로 건) 사람 중에서** 뽑아서 다음 페이지를 쓰게 함
- 거짓으로 쓰면 **맡긴 코인을 뺏김** → **슬래싱(Slashing)**
- 쓰는 사람 = **검증자(Validator)**. 전기를 훨씬 적게 씀
- 🏦 비유: 보증금을 낸 사람이 쓸 권리를 갖고, 속이면 보증금 몰수
- 예: **이더리움, 솔라나, Fogo** 등 대부분의 최신 블록체인

## 5. 핵심 정리 ✏️
1. **블록 = 거래 기록이 담긴 페이지**, **블록체인 = 페이지들이 순서대로 묶인 공책**
2. 각 페이지는 **앞 페이지의 지문(해시)** 을 갖고 있어서 몰래 고치기 거의 불가능
3. 공책 복사본을 가진 컴퓨터 = **노드**
4. 다음 페이지를 누가 쓸지 정하는 규칙 = **합의 방식**
   - **PoW:** 퍼즐 경쟁, 채굴자 (비트코인)
   - **PoS:** 코인 맡기기, 검증자 (이더리움 등)
