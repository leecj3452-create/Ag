# 시도별 매출 타겟 배분

Agilent 소모품 국내 지역 타겟 검토용 페이지입니다. `index.html` 하나로 동작합니다.

- 17개 시도의 연구개발비 비중, 2024년 GRDP(명목), 인구를 담았습니다.
- 지표별 가중치(기본값: R&D 70 · GRDP 30)로 시도별 적정 매출 비중을 계산합니다.
- 시도를 AM 3명에게 배정하면 AM별 적정 비중과 목표 금액이 나옵니다.
- 실제 매출을 넣으면 시도·AM별 달성 지수(실제 비중 ÷ 타겟 비중 × 100)를 보여줍니다.

데이터: 과기정통부·KISTEP 연구개발활동조사(2022·2023), 국가데이터처 2024년 지역소득(잠정),
행정안전부 주민등록인구(2025). `*` 표시는 추정치입니다.
