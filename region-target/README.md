# 시도별 매출 타겟 배분

`index.html` 하나로 동작하는 영업 타겟 도구입니다.

- 17개 시도(도 9 + 특별시·광역시·특별자치시 8)의 2024년 GRDP(명목)와 인구를 담았습니다.
- GRDP와 인구의 가중치를 정해 시도별 "적정 매출 비중"을 계산합니다.
- 각 시도를 AM 3명에게 배정하면 AM별 적정 비중과 목표 금액이 계산됩니다.
- 실제 매출을 넣으면 시도·AM별 달성 지수(실제 비중 ÷ 타겟 비중 × 100)를 보여줍니다.

데이터: 국가데이터처 「2024년 지역소득(잠정)」(2025.12), 행정안전부 주민등록인구(2025).
일부 시도 GRDP는 발표된 1인당 GRDP로 역산한 추정치이며 표에 `*`로 표시했습니다.
