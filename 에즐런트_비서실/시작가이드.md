# 비서실 시작 가이드

회사 Windows PC에서 비서실을 처음 여는 방법과 매일 쓰는 방법입니다. 순서대로 따라 하면 됩니다.

---

## 1단계: 비서실 폴더를 회사 PC로 가져오기 (처음 한 번)

### 방법 A: 압축 파일로 내려받기 (추천)

1. 회사 PC의 브라우저에서 GitHub에 로그인합니다.
2. 아래 주소를 주소창에 붙여넣고 Enter를 누릅니다. 압축 파일(.zip)이 내려받아집니다.
   ```
   https://github.com/leecj3452-create/Ag/archive/refs/heads/claude/dazzling-wright-ph3i2u.zip
   ```
3. 내려받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 **"압축 풀기"**를 고릅니다.
4. 압축을 푼 폴더 안의 **`에즐런트_비서실`** 폴더를 **문서** 폴더로 옮깁니다.
   - 결과: `문서\에즐런트_비서실`

### 방법 B: GitHub 접속이 막혀 있을 때

1. 문서 폴더에 `에즐런트_비서실` 폴더를 직접 만듭니다.
2. 아래 3단계처럼 그 폴더에서 Claude를 실행합니다.
3. 이 대화에서 만든 파일(`CLAUDE.md`, 직원 파일 3개)의 내용을 복사해서 Claude에게 붙여넣고 이렇게 말합니다.
   > "이 내용으로 CLAUDE.md 파일을 만들어줘"
   - 직원 파일은 `.claude\agents\` 폴더 안에 같은 이름으로 만들어 달라고 하면 됩니다.

---

## 2단계: 자료 넣기 (처음 한 번 + 새 자료가 생길 때마다)

파일 탐색기에서 아래처럼 복사해 넣습니다. **복사**하세요. 원본은 원래 위치에 그대로 둡니다.

| 넣을 자료 | 넣을 폴더 |
|---|---|
| 견적서 PDF 전부 | `01_원본_견적서` |
| 구매이력 Raw 엑셀 + 매일 업데이트하는 엑셀 | `02_원본_구매이력` |
| 서류 양식 (HWP는 PDF로 변환해서) | `03_서류양식` |

`04_작업데이터`, `05_결과물`은 비워 두세요. Claude가 채웁니다.

---

## 3단계: 비서실 열기 (매일)

1. 파일 탐색기에서 `문서\에즐런트_비서실` 폴더를 엽니다.
2. 위쪽 **주소창**을 한 번 클릭합니다.
3. 주소창에 `powershell`이라고 입력하고 Enter를 누릅니다.
   - 왜: 이렇게 하면 터미널이 **이 폴더에서** 바로 열립니다. 폴더 이동 명령어(`cd`)를 따로 칠 필요가 없습니다.
4. 파란(또는 검은) 터미널 창이 열리면 아래를 입력하고 Enter를 누릅니다.
   ```
   claude
   ```
   - 왜: Claude를 실행합니다. 이 폴더에서 실행하면 Claude가 `CLAUDE.md`(비서실장 지침서)를 자동으로 읽습니다.
5. 처음 실행할 때 "이 폴더의 파일을 신뢰하나요?" 같은 질문이 나오면 **Yes**를 고르고 Enter를 누릅니다.

이제부터는 **한국어로 말하듯이** 지시하면 됩니다. 명령어는 더 필요 없습니다.

---

## 4단계: 첫날 할 일 (순서대로)

아래 문장을 그대로 복사해서 Claude에게 보내세요.

**① 직원 확인**
> 비서실 직원 3명이 잘 등록됐는지 확인해줘.

**② 구매이력 구조 파악** (가장 중요)
> data-manager에게 02_원본_구매이력 폴더의 엑셀 파일들을 확인시키고, 어느 열이 고객사·주문일·품목번호·수량·금액인지 표로 보고해줘.

Claude가 보고한 표를 보고 틀린 곳이 있으면 고쳐서 알려주세요.

**③ 견적대장 만들기**
> 견적서 PDF를 전부 읽어서 견적대장을 만들어줘. 구매이력과 대조해서 발주 여부도 표시해줘.

견적 10건 정도를 골라 원본 PDF와 숫자가 맞는지 직접 확인해 주세요.

**④ 첫 콜리스트**
> 오늘 콜리스트 10곳 만들어줘.

## 막힐 때

| 상황 | 해결 |
|---|---|
| 보안 경고 창이 뜸 | 무리해서 허용하지 말고 Claude에게 "보안 경고가 떠서 못 했어. 다른 방법 알려줘"라고 말하세요 |
| Claude가 명령어를 실행해도 되냐고 물음 | 무슨 일을 하는 명령어인지 모르겠으면 "이게 뭐 하는 거야?"라고 먼저 물어보세요 |
| HWP 양식 | 한글 프로그램에서 **파일 → PDF로 저장** 후 `03_서류양식`에 넣으세요 |
| Claude가 지침을 잊은 것 같음 | "CLAUDE.md 다시 읽고 따라줘"라고 말하세요 |
| Claude 끝내기 | `/exit` 입력 후 Enter, 또는 터미널 창 닫기 |
